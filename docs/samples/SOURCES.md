## 2. 来源与公开性

### 2.1 `hypertension-2025.pdf`

- 文献：国家心血管病中心、国家基本公共卫生服务项目基层高血压管理办公室、
  国家基层高血压管理专家委员会《国家基层高血压防治管理指南 2025 版》。
- 出处：中国循环杂志，2025 年 9 月，第 40 卷第 9 期，第 836–850 页。
- 下载：国家心血管病中心基层高血压管理办公室“下载专区”
  `https://hbp-office.nccd.org.cn/files/国家基层高血压防治管理指南2025版.pdf`
  （下载时对中文路径做了 URL 编码）。
- 公开性：官网 2025-09-26 发布新闻《〈国家基层高血压防治管理指南2025版〉发布》，
  明确新版指南同步在《中国循环杂志》和《中华心血管病杂志》发布、“供免费下载学习”。
- 用途：`docKey=hypertension-guideline`、`version=2025`、`effectiveFrom=2025-01-01`，
  作为当前版本与主评测语料。

### 2.2 `hypertension-2024.pdf`

  4.2.2 诊断流程中的首诊阈值同步改为 150/95 mmHg；其余文字照录。
- 标记：文首有“使用声明”，每页页脚为“测试用摘编 · 非正式版本 ·

## 3. 版本/冲突测试锚点

| 条款 | `hypertension-2025.pdf` | `hypertension-2024.pdf` | 说明 |
|---|---|---|---|
| 4.2.1 诊室血压诊断标准 | ≥140/90 mmHg | ≥150/95 mmHg | **主冲突点** |
| 4.2.1 家庭血压诊断标准 | ≥135/85 mmHg | ≥135/85 mmHg | 相同 |
| 4.2.1 动态血压诊断标准 | 24h≥130/80；白天≥135/85；夜间≥120/70 | 同左 | 相同 |
| 5.2 降压目标 | <80 岁 130/80；≥80 岁 150/90 | 同左 | 相同，避免多处冲突 |
| 8.1 随访频率 | 达标 ≥3 个月 1 次；未达标每月 1 次 | 同左 | 相同 |

  8.1 在**第 13 页**（848）。
- 2024 摘编：4.2 在第 1 页、5.2 与 8.1 在第 2 页。

## 4. 解析注意

- 2025 版是期刊双栏排版，第 3 页是诊断流程图。PDFBox/pdftotext 可能把流程框文字拆成
  碎片、或把左右栏串在一起；解析回归建议用第 4 页正文（4.2 诊断标准）做基准。
- 2020 版是单栏 35 页，适合和 2025 版做 fixed/heading 切分对比。
- 企业内控规范是单栏 8 页，章节标题“第一章 …”可被
  `第[一二三四五六七八九十百]+[章节条]` 规则命中，适合验证 heading 切分。
- 三篇文档都含编号条款（4.2.1、第五条等），可用于 `clauseId` 提取测试。

## 5. 校验命令

PowerShell：

```powershell
Get-ChildItem docs\samples\*.pdf | ForEach-Object {
  $h = (Get-FileHash $_.FullName -Algorithm SHA256).Hash.ToLower()
  "{0}`t{1}`t{2}" -f $_.Name, $_.Length, $h
}
pdftotext docs\samples\hypertension-2025.pdf - | Select-Object -First 5
```

Git Bash / Linux：

```bash
sha256sum docs/samples/*.pdf
pdftotext docs/samples/hypertension-2025.pdf - | head
```
